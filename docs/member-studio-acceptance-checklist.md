# Member Studio Acceptance Checklist

这份清单用于每次会员谱坊发布前的人工验收。只使用专门的测试会员，不要把真实会员资料、密码、电邮、手机号或 Supabase 密钥写入文件、截图或 Git。

## 账户与权限

- [ ] 会员可以用会员号登录，并被要求修改一次性初始密码。
- [ ] 会员修改后的密码至少 8 位，同时含字母和数字。
- [ ] 会员只能看到自己的书、章节、族人和私有图片。
- [ ] 会员 A 无法读取或修改会员 B 的任何记录或 Storage 文件。
- [ ] 管理员可以开通会员、查看必要的会籍联络资料和重设初始密码。
- [ ] 管理员不会看到密码 hash，也不会再次取得已经显示过的一次性密码。

## 八大招

- [ ] 封面书名和第一代开族始祖为必填，授权确认会被保存。
- [ ] 每一章保存后重新打开，内容仍然存在；完成标记不会锁死编辑。
- [ ] 迁徙、童年和家肴的重复项目可以新增、修改、删除。
- [ ] 世系族人可以新增、修改，关系显示没有断线或空白节点。
- [ ] 电话和地址只出现在会员自己的资料页和管理员范围内。

## 图片与隐私

- [ ] JPG、PNG、WebP 可以上传；非图片或超过 10 MB 的文件会被拒绝。
- [ ] 上传图片可预览、加说明和删除；刷新页面后仍可看到自己的图片。
- [ ] 图片没有公开 URL；未获审核的图片不会出现在公共网站。
- [ ] 公共页面 HTML、公开故事和日志不含私有电话、地址或原始家谱内容。

## 发布前检查

- [ ] `npm run check:astro` 通过。
- [ ] `npm run build` 通过。
- [ ] 中英文公共页仍可在没有 Supabase 密钥的本地构建中打开。
- [ ] Git diff 中没有 `.env`、密码、service-role key 或测试会员资料。
- [ ] GitHub Pages workflow 成功，线上会员登录入口可打开。
