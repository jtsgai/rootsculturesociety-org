# Studio fields — Eight Methods (Phase 1)

One membership = one genealogy book. All fields private by default.
Generation rule: Generation 1 = first ancestor who settled in Singapore.

## Book header (created at Method 1)

| Field | Required | Notes |
|---|---|---|
| Book title | Yes | e.g. 黃氏相册家谱 |
| Generation-1 ancestor name | Yes | Singapore founding ancestor of this branch |
| Cover image | No | Family photo or decorative image |
| Dialect group | No | |
| Ancestral place | No | |
| Consent tick | Yes | Member warrants authority to enter relatives’ data |

## Method 1 Cover
Title, ancestor, cover image, short dedication.

## Method 2 Surname origin
Long text + images. No mandatory scholarly citations.

## Method 3 Migration
Repeating place rows: place, year (optional), note, image.

## Method 4 Ancestral culture
Dialect, hall name (tanghao), ancestral house / temple / clan association notes + images.

## Method 5 Lineage
Person card:

| Field | Required | Visibility |
|---|---|---|
| Name | Yes | Private |
| Generation number | Yes | Auto from parent if possible |
| Sex | No | |
| Living / deceased | No | |
| Father / mother | No | Links |
| Spouse | No | Links |
| Children | No | Links |
| Birth year | No | Private; never on public site |
| Photo | No | Private |
| Note | No | |

Do not show phone or address on this step.

## Method 6 Childhood
Timeline rows: years, place in Singapore, story, photos.

## Method 7 Family dishes
Dish name, ingredients, method, photo.

## Method 8 Family register
Same persons as Method 5 plus optional occupation and education.
Phone and address: optional, **admin-only + owner-only**, never in any public view.

## Out of Phase 1
PDF export, print layout, AI writing, AI image, AI video, self-registration, payment, multi-editor family accounts.
