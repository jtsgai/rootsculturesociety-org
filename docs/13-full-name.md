# Official names — use in full

- Chinese (never shorten on the public site): 新加坡根缘文化学会
- English (never shorten on the public site): Roots Culture Society of Singapore

Do not use: 根缘学会, 根文化学会, Roots Culture Society, RCSS as the only on-page name (RCSS may appear in a file name or member ID prefix only).
Header, footer, browser title, and contact pages must show the full name in the language of that page.
