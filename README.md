# Roots Culture Society of Singapore

新加坡根缘文化学会的双语公共馆，使用 AstroWind（Astro 7 + Tailwind CSS 4）作为工程骨架，并已重做为文化机构视觉，不保留默认 SaaS 外观。

## 本地启动

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可预览。生产构建：

```bash
npm run build
```

中文页在 `/`，英文页在 `/en/`；两种语言均提供首页、学会、执委会、相册家谱、出版、故事、活动、入会、寻根路径、隐私、条款和联络页。

## 范围

本阶段只做静态公共馆，不包含登录、数据库、谱坊、收款或 AI 生成接口。入会只提供秘书长 WhatsApp：9272 8933，以及 `ianchungcy@gmail.com`。

Logo 使用本机提供的 PNG，并以圆形裁切显示。出版页使用本机提供的 `2025年出版.jpeg` 与 `2026年出版.jpeg`；家庭样本 PDF、家庭照片和姓名地址表没有公开。
